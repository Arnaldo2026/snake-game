# Game Room – versions

The version is in the `VERSION` file and shows on the home screen (bottom), next to the commit it was built from.
Bump it with every change pushed: the last number for fixes, the middle one for new features or games.

## 1.0.0 – 2026-10-20
First numbered version. Includes Snake, Space Wars, Asteroids, Lunar Lander, Battlezone, Pong Tennis and
Breakout; public/private rooms; Space Wars arena shapes, reverse thrust and the Thumbs and Slide phone layouts.
